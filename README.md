# WHITE BLANK — 白い地下迷宮

壁も床も天井も、すべて白い。光源はどこにもない。
それでも形が読めるのは、隅に落ちたわずかな陰りと、板の継ぎ目だけがあるからだ。

無限に広がる地下の迷路を、一人称で歩く。
やることはひとつ。世界にたったひとつだけある扉を見つけて、くぐること。

ブラウザだけで動く。ビルドも、素材ファイルもない。

## 遊びかた

```
python3 -m http.server 8080     # あるいは任意の静的サーバ
```
`http://localhost:8080` を開く。
（`file://` では ES モジュールが読めないので、必ずサーバ越しに）

|---|---|
| `W` `A` `S` `D` | 歩く |
| マウス | 見まわす（画面をクリックすると視点が固定される） |

## この世界のきまり

**世界は保存されない。** チャンクは、種と座標から必要になった分だけ計算し直される。
だから引き返せば、さっき通った通路がそのままそこにある。
遠ざかれば忘れられ、戻れば同じ形でまた組み上がる。無限に歩けるのはそのためだ。

**同じ種なら、同じ世界。** 種は覚えやすい名前で表示される。誰かと同じ迷宮を歩ける。

**上下にもつながっている。** 平面の迷路ではない。

- **階段** — 登れる。降りられる。中央を占めるので、脇に細い通路が残る
- **斜路** — 段のない、ひと続きに傾いた坂。床にも壁にも平行でない面がひとつ混じるだけで、
  白い直方体の連なりが急に立体に見えはじめる
- **落下穴** — 床にあいた四角い穴。落ちたら、そこから登る道を別に探すことになる

落下穴は一方通行だ。だから「落ちた先に登る道がない窪地」を作らないよう、
生成のときに**歩いて往復できることを確かめている**（下の節を参照）。

**壁の印。** ところどころの壁に、誰が刻んだのかわからない記号がある。
位置も形も座標から決まっているので、道しるべになる。
足りなければ `E` で自分の印を刻める（種ごとにブラウザに残る）。

**音。** 足音は歩いた距離で刻まれ、空間の開けぐあいで残響の長さが変わる。
ときおり遠くで何かが崩れ、何かが軋む。姿は決して見えない。
扉が近づくと、その方向から低い唸りが聞こえはじめる。

### 無限なのに、ちゃんとつながっている理由

無限の迷路でいちばん難しいのは、「どこへでも歩いて行ける」ことの保証だ。
世界全体を見渡せない以上、局所的な規則だけでそれを成り立たせないといけない。

1. チャンクの中の空洞は、まず**ひとつながりの塊だけを残す**（孤立した空洞は岩に戻す）
2. その塊を**全域木で掘る**ので、チャンク内のどの空洞からどの空洞へも行ける
3. 隣り合うチャンクの境界面には、**必ず出入口を開ける**

3 の出入口は、面を共有する 2 つのチャンクのうち座標の小さいほうを基準に乱数を引く。
だから両側がそれぞれ勝手に計算しても、寸分たがわず同じ位置に穴が開く。
2 と 3 から、無限のチャンク格子はひとつながりになる。

床に穴を開けるときも同じ用心がいる。面を 4×4 のタイルに割って抜くのだが、
**抜いた残りが必ず四辺すべてに接して連結する形**しか選ばない。
そうしないと、穴の向こう側の通路へ渡れなくなってしまう。

### 落ちたきり戻れない場所を作らない

つながっているだけでは足りない。落下穴は一方通行だからだ。
実際、素朴に作ると数%のセルが「行けるが帰れない」窪地になり、
運が悪いと**始まりの場所そのものが出られない穴の底**になる（種 8080 がそうだった）。

そこで、**往復できる辺**——水平リンクと階段だけ——を使ってチャンク内の連結成分を数え、
ばらけている間だけ落下穴を階段に変える。必要な数しか変えないので、穴はちゃんと穴のまま残る
（およそ 17 セルにひとつ）。チャンク内が往復できて、境界の出入口が水平なら、
世界全体がどこからでも往復できることになる。

`tools/reach.mjs` が、この性質を毎回たしかめている。
「行ける場所の集合」と「帰ってこられる場所の集合」を両方向から塗って、一致するかを見る。

### 試験

```
npm install          # three と playwright（同梱のChromiumを使う）
node tools/reach.mjs # 行った先から必ず帰ってこられるかを確かめる（ブラウザ不要）
node tools/check.mjs # 登る・落ちる・刻む・くぐる・沈まないを実際に確かめる
node tools/shot.mjs  # 実際に歩いて shots/ に絵を残す
```

`check.mjs` は描画を待たずに世界の時間だけを進めるので、
機械の速さに関係なく同じ結果になる。
